🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Problem: "npm: command not found"
Solution: Install Node.js from https://nodejs.org/

Problem: "Port 3000 is already in use"
Solution: 
   - Find and kill process: lsof -i :3000
   - Or change PORT in server.js (line 12)

Problem: "Cannot find module 'express'"
Solution: Run: npm install

Problem: Demo login doesn't work
Solution:
   - Stop server (Ctrl+C)
   - Delete db.json: rm db.json
   - Restart: npm start
   - Try login again

Problem: Old registration form (missing new fields)
Solution:
   - Clear browser cache (Ctrl+Shift+R)
   - Or open in incognito/private mode

📞 NEED HELP?
═══════════════════════════════════════════════════════════════════════

Check:
1. Node.js installed: node --version
2. npm installed: npm --version
3. In correct folder (should see server.js)

5. Server running (check terminal)
